# Varshit Jha Portfolio

A personal portfolio website for Varshit Jha, focused on frontend development work, skills, projects, resume access, and contact links.

## Live Preview

This is a static website. Open `index.html` in a browser, or deploy the repository with GitHub Pages.

## Built With

- HTML5

- JavaScript
- Google Fonts

## Features

- Responsive single-page portfolio layout
- About, skills, projects, and contact sections
- Resume download link
- GitHub and LinkedIn profile links
- Lightweight static deployment workflow

## Deployment

This project can be deployed with GitHub Pages:

1. Push the `portfolio` folder as its own GitHub repository.
2. In GitHub, open repository `Settings`.
3. Go to `Pages`.
4. Set the source to the `main` branch and root folder.
5. Save and wait for GitHub Pages to publish the site.

## Notes

- Review `assets/resume/resume.pdf` before publishing because resumes often contain personal contact details.
- Replace placeholder or empty image files before final public deployment if needed.
